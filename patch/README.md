# OS patching of the Google VM (free-vm)

Short version. The design, the other machines and the secrets (names only) are in <home-server-repo> `ops/patch/README.md`.

- **What:** **Google VM Manager** (OS Config) installs the updates on this VM: the weekly patch deployment `weekly-apt` in `infra/patch-deployment.tf` (Tuesday 22:00 UTC, apt upgrade, reboot NEVER). Free for up to 100 VMs per billing account (this project has one), so no charge; needs `osconfig.googleapis.com` and two roles from `bootstrap/main.tf` (run `scripts/bootstrap.sh` once). `apply-patching.sh --installer osconfig` turns apt's own unattended-upgrades off so two tools never fight over dpkg; set the variable `patch_installer = "unattended"` to go back to unattended-upgrades (security updates daily, `Automatic-Reboot "false"`). `patch-agent` (last run read from `/var/log/apt/history.log`; failures also in `gcloud compute os-config patch-jobs list`) reports to ntfy.sh and the Home Kuma, reminds you every 3 days while a reboot waits (first alert as soon as one is needed) (mode `alert`, your pick), and after every boot checks Docker, Tailscale (`kuma_tailscale`), the Kuma containers and the heartbeat sender (`kuma_push`): if something is missing it sends an ntfy alert with the machine name.
- **Night:** Wednesday 00:00 UTC (04:00 local time), only used in mode `staggered` (`patch_reboot_mode` in `infra/variables.tf`). Home is Monday, the Oracle micros Friday.
- **Files here:** `patch-agent`, `apply-patching.sh` (identical copies, shipped inside the startup script by `infra/vm.tf`), `test_patch_agent.py`.
- **Apply to the existing VM without rebuilding it:** merge, run the tofu apply, then `sudo google_metadata_script_runner startup` on the VM (`docs/WHAT-YOU-DO.md`, D1). Or copy the two scripts with `gcloud compute scp` and run `apply-patching.sh` by hand (same page).
- **Tests:** `cd patch && python3 -m unittest test_patch_agent` (fake apt/docker/systemctl and a local HTTP server; the compose test also checks that every service in this repo has `restart: unless-stopped`).
- **Untested on the real VM:** the units under real systemd, ntfy.sh over IPv6, the first real VM Manager patch job (Tuesday 22:00 UTC) and what it writes to the apt history, the reboot-to-back time of an e2-micro.
